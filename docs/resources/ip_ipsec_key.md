# routeros_ip_ipsec_key (Resource)
Manages an IPsec RSA key. Uses /ip/ipsec/key/rsa on RouterOS 7.20 and newer, and /ip/ipsec/key on older firmware.

The resource generates an RSA key and selects the native menu from the connected
router's firmware version for every operation. RouterOS 7.20 and newer use
`/ip/ipsec/key/rsa`; older supported firmware uses `/ip/ipsec/key`. Existing state
IDs and Terraform resource addresses stay the same when upgrading RouterOS.

## Example Usage
```terraform
resource "routeros_ip_ipsec_key" "test" {
  name     = "test-key"
  key_size = 2048
}
```

## Import

Find the internal ID in the router console with `/ip/ipsec/key/rsa print show-ids`
on RouterOS 7.20 and newer, or `/ip/ipsec/key print show-ids` on older firmware.
Import by internal ID, key name, or an attribute selector matching one key:

```shell
terraform import routeros_ip_ipsec_key.test '*3'
terraform import routeros_ip_ipsec_key.test 'name=test-key'
```

OpenTofu and Terraform import blocks use the same selectors:

```terraform
import {
  to = routeros_ip_ipsec_key.test
  id = "name=test-key"
}
```
